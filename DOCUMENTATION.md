## About This Project / 关于本项目

**English**: This VS Code extension provides a local HTTP proxy server for the VS Code Language Model API, supporting both OpenAI Chat Completions and Anthropic Messages API formats. Access GitHub Copilot's backend models through a standardized REST API.

**中文**: 这个 VS Code 扩展为 VS Code 语言模型 API 提供了一个本地 HTTP 代理服务器，支持 OpenAI Chat Completions 和 Anthropic Messages API 两种格式。通过标准化的 REST API 访问 GitHub Copilot 的后端模型。
